5. 임베딩 — Skip-gram 100d → NTN 100d

① 단어 임베딩 (skip-gram + negative sampling, GPU)

코퍼스 = 링크된 제목의 내용어(명사류+동사·형용사) · 어휘집 V = 24,859 (빈도 ≥ 5) 상위 어휘 실측: 목표, 현대차, 1, 삼성전자, 리포트, 분기, 브리핑, 2 … 쌍 800만 (window≤5) · 4 epoch · loss 2.11→1.89 · 파라미터 2×V×100 ≈ 497만

② 이벤트 임베딩 (Neural Tensor Network, Ding et al. 2015 Eq.1)

입력: O1, P, O2 ∈ R¹⁰⁰ (각 인자 = 구성 단어벡터 평균) R1 = tanh( O1ᵀ T1 P + W1[O1;P] + b1 ) T1 ∈ R^(100×100×100) R2 = tanh( Pᵀ T2 O2 + W2[P;O2] + b2 ) T2 ∈ R^(100×100×100) U = tanh( R1ᵀ T3 R2 + W3[R1;R2] + b3 ) T3 ∈ R^(100×100×100) → U = 이벤트 벡터(100d) 학습: margin loss max(0, 1 − s(E) + s(E^r)) + 10⁻⁴‖Φ‖² (E^r = 인자 1개를 무작위 단어로 교체) 파라미터 ≈ 306만 · 실측 수렴: hinge 0.22, margin충족 78% 산출: 뉴스별 100d 벡터 124,190개 (학습분포 기준 차원별 표준화) — 실측 예: [−0.004, −0.005, −0.003, −0.006, −0.025, 0.003, …]
